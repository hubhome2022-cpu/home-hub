# Home Hub — Google Sheet schema (Phase 1 proposal)

**Status:** approved 2026-10-17 (miles · weeks start Sunday · dinner only · chore points as proposed).

One spreadsheet, **"Home Hub Data"**, in Jeremy's Google Drive. One tab per table. Row 1 is the header row (exact names below). The Apps Script API is the only thing that writes to it. You can still view and edit it by hand; the dropdowns below keep hand edits safe.

---

## Rules that apply to every tab

**Standard columns.** Every tab except `Settings` starts with these five:

| Column | Type | Notes |
|---|---|---|
| `id` | text | Short, unique, with a tab prefix: `rcp_7f3k9q`, `chr_a81mz2`. Generated by the app or script. **Never edit or reuse it.** |
| `created_at` | timestamp | Set once. |
| `updated_at` | timestamp | Updated on every change. Sync reads this to find what changed. |
| `updated_by` | member id | Who made the last change (`mem_jeremy`), or `system` for the script. |
| `deleted` | TRUE/FALSE | Soft delete. Rows are hidden in the app, never removed. A yearly cleanup can archive them. |

**How values are stored**
- **Timestamps** are stored as ISO 8601 text in UTC, e.g. `2026-10-17T12:42:00Z`. **Dates** (no time) are `YYYY-MM-DD` text. Date and timestamp columns are formatted as **plain text**, so Sheets can't auto-convert them into its own date format. That's the most common way homemade Sheet backends break.
- **Members** are stored by id (`mem_jeremy`, `mem_allison`). The special value `family` means everyone.
- **Lists inside one cell** use a comma for short lists (tags, member ids) and a new line for long lists (ingredients, steps). Both are easy to edit by hand.
- **Booleans** are real `TRUE`/`FALSE` values, shown as checkboxes in the Sheet.
- **Computed columns** (marked ⚙) are written only by the script. If you edit one by hand, the next recompute overwrites it.

### `ChoreLog`
Append-only history; streaks, weekly points and "who did what" all come from here.

`chore_id`, `done_at`, `done_by` (member id), `points` (copied at completion so later changes don't rewrite history), `skipped` (TRUE when you tap "Skip this time": it moves the due date forward without points), `note`, `due_date` (the due date this completion took care of, so doing Tuesday's trash on Monday doesn't make it due again on Tuesday) (+ standard columns).

### `Rooms`
`id`, `name`, `sort_order` (+ standard columns). One list shared by Chores and Projects. Seed: Kitchen, Living room, Bedroom, Guest room, Bathrooms, Laundry, Basement, Garage, Utility, Yard, Deck, Whole house, Scout.

## Not in the Sheet, on purpose
- **Calendar events** live in Google Calendar.
- **Secrets** (household key, SmartThings token) live in Apps Script's Script Properties.
- **Photos** live in Google Drive or Google Photos. The Sheet stores only links.

## Size check
At your household's pace, `ChoreLog` grows about 3,000 rows a year and `WorkoutSets` about 5,000. Sheets handles hundreds of thousands of rows, and the app only downloads changed rows after the first sync. That leaves years of headroom; a yearly archive step is built in anyway.
